# ТЗ: браузерная игра «Заказ горит!»

Oct 19, 2026 · @Evgenia

## 1. Общие сведения

Делаем бесплатную браузерную пиксельную игру для клиентов компании: смешную, короткую, про закулисье оптовых поставок крепежа. Игра работает на имидж и узнаваемость бренда, а услуги компании вшиты в сюжет мягко, без рекламных вставок.

| Параметр | Значение |
| --- | --- |
| Рабочее название | «Заказ горит!» (запасное — «Резьба судьбы») |
| Жанр | 2D-платформер с мини-играми, пиксель-арт |
| Аудитория | Клиенты: закупщики, владельцы малого бизнеса, мастера, строители, 30–55 лет, в основном мужчины |
| Платформы | Браузер на ПК и телефоне (телефон — горизонтально), без установки |
| Цена для игрока | Бесплатно, без регистрации в MVP |
| Длительность MVP | 15–25 минут на полное прохождение |
| Референс | [«Астра: Хроники Нижней Волги»](https://www.starkovpro.ru/) — местные боли превращены в игровые действия |

**Цели игры:**

- Вызвать у клиента узнавание и улыбку: «это же про нас».
- Дать повод для касаний: рассылка, соцсети, QR на новогодних подарках, ссылка на сайте.
- Мягко показать, что компания умеет: антикоррозийное покрытие, покраска, доставка из Китая, изготовление по чертежам.

**Открытые вопросы:**

- Дедлайн запуска: к Новому году или без жёсткой даты?
- Полный список услуг, которые можно упомянуть в игре.
- Нужны ли платные инструменты: подписка Claude с Claude Code, по желанию Aseprite.

## 2. Концепция и лор

Игрок — стажёр в первую неделю работы. Он проводит Заказ Века через все отделы компании и побеждает Королеву Коррозию. Все проблемы в игре создаёт злодейка, а сотрудники их героически решают: так юмор работает на имидж.

**Завязка.** Пятница, 16:47. Стройке нужен крепёж для огромного объекта, отгрузить надо до понедельника. Ночью просыпается Королева Коррозия: она хочет, чтобы всё в мире разболталось и проржавело. Её союзник — Питерская Сырость, в дождливых зонах враги сильнее.

**Финал.** Битва с Коррозией на строящемся мосту, последний удар — горячим цинкованием. Финальный экран: «Всё держится на людях».

**Сквозной побочный квест.** Болт М12 ищет свою гайку с шагом 1,75. Он встречается во всех мирах, в финале — воссоединение.

## 3. Геймплей

Основа — простой 2D-платформер с горизонтальной прокруткой: бег, прыжок, одно действие. Между уровнями и внутри них — мини-игры на 10–30 секунд для разнообразия. Сложность рассчитана на человека, который давно не играл: пройти можно с первого-третьего раза.

### Управление

| Действие | ПК | Телефон |
| --- | --- | --- |
| Движение | Стрелки или A/D | Экранные кнопки слева |
| Прыжок (двойной с Шайбой) | Пробел или W | Кнопка справа |
| Действие (взять, ударить, использовать) | E или Shift | Вторая кнопка справа |
| Пауза | Esc | Кнопка в углу |

На телефоне игра просит повернуть экран горизонтально. Кнопки крупные, не меньше 48×48 px.

### Сквозные механики

- **Здоровье:** 3 деления. Удар врага снимает одно.
- **Жизни:** 3 на старте. Каждые 100 собранных болтов дают +1 жизнь.
- **Чекпоинты:** турникеты-проходные в середине уровня, «отметился на проходной».
- **Смерть:** экран «Ушёл на перерыв. Вернёшься?» и рестарт с чекпоинта.
- **Конец жизней:** рестарт уровня, не всей игры.
- **Сохранение:** прогресс по мирам хранится в браузере игрока.
- **Коллекция:** на каждом уровне спрятаны 3 «Карточки стандартов» с реальным фактом про DIN, ISO или ГОСТ. Повод перепройти.

## 5. Услуги компании в игре

Услуги появляются как часть мира: сюжет, отдел, бонус или звонок-приколюха. Рекламных вставок, баннеров и всплывающих окон во время игры нет. Прямое упоминание — один раз, в финальных титрах.

| Услуга | Где в игре | Как подано |
| --- | --- | --- |
| Антикоррозийное покрытие | Весь сюжет, бонус Цинк, финал | Злодейка — Коррозия, победить её можно только цинкованием |
| Покраска крепежа | Бонус «Порошковая покраска», звонок в мире Продаж | Архитектор просит крепёж «в цвет фасада, но чуть теплее» |
| Изготовление по чертежам | Мир Цех | Технолог собирает деталь даже по салфетке |
| Доставка из Китая | Мир Закупки | Контейнер плывёт из Китая, засыпает на Китайский Новый год |

**Финальные титры.** После «Всё держится на людях» — одна строка: «Кстати, цинкуем, красим, возим из Китая и делаем по чертежам по-настоящему», и ссылка на сайт. Формулировку и ссылку согласовать с коммерцией.

**Ограничения:**

- В игре не называем конкретных сроков, цен, видов покрытий и гарантий. Всё, что клиент увидит, он воспримет как обещание.
- Новые услуги добавляем тем же способом: отдел, бонус или звонок-приколюха.

## 6. Тексты и юмор

Принцип: «вокруг хаос, а мы с ним справляемся», а не «у нас хаос». Все тексты пишет и вычитывает Евгения, перед запуском их согласует руководство.

### Правила безопасности юмора

- Никаких шуток про брак, недовес, сорванные сроки по вине компании, долгие перезвоны.
- Обходим откаты, «серые» схемы, налоги, оплату наличными.
- Водители: никаких шуток про превышение, перегруз, штрафы, алкоголь.
- Клиент никогда не злодей. Шутим над ситуацией («Загадочная Фотка»), а не над человеком.
- Реальные сотрудники — только собирательные образы или камео с письменного согласия.
- Никаких чужих брендов и персонажей: WD-40 — «проникающая смазка», логотипов поставщиков и конкурентов нет.
- Факты на Карточках стандартов — только проверенные по документам.

### Экраны загрузки

- Затягиваем с моментом 25 Н·м…
- Пересчитываем болты поштучно (их 48 000)
- Ищем гайку от этого болта
- Ждём оригиналы с синей печатью
- Калибруем штангенциркуль
- Сушим склад после питерского дождя
- Расшифровываем чертёж на салфетке

### Ачивки

| Ачивка | Условие |
| --- | --- |
| Нашёл чайник | Пройти пролог |
| Мастер по фото | Угадать 10 метизов по силуэту |
| Не тот шаг | Попробовать накрутить гайку с неподходящим шагом |
| Прошёл склад без рохли | Пройти Склад, ни разу не сев на рохлю |
| Салфетка — тоже чертёж | Собрать деталь по чертежу на салфетке |
| Антикоррозийный | Пройти мир без урона от Ржавчины |
| Затянул до пятницы | Пройти игру целиком |

### Реплики NPC (стартовый набор)

- Дед Штангенциркуль: «Обычных болтов не бывает. Бывают стандартные».
- Технолог: «Салфетка — тоже чертёж. Если на ней есть размеры».
- Водитель: «Навигатор сдался. Водитель — нет».
- Бухгалтерия: «Без оригинала вас не существует».
- Маркетинг: «Нужно креативно, но как в прошлый раз».
- NPC на складе: «Самосборная коробка: собирается сама, если очень попросить».

Полный сценарий диалогов пишется на этапе геймдизайна, отдельным файлом.

### Звук

- **Музыка:** чиптюн, 4 трека для MVP: меню, офис, цех и склад, финальный бой. Каждый трек — зацикленный, 1–2 минуты. Делаем скриптом в Claude Code: ноты в коде, синтез квадратной и треугольной волной, шум для ударных.
- **Эффекты:** около 20 штук: прыжок, болт, урон, бонус, звонок телефона, печать, рохля, победа, смерть. Можно сделать бесплатно в генераторе jsfxr.
- **Права:** всё, что сгенерировано своим кодом, принадлежит компании. Если берём готовую музыку — только с лицензией на коммерческое использование, лицензию сохраняем.
- **Настройки:** отдельные регуляторы музыки и звуков, звук по умолчанию включён тихо.

## 8. Технические требования

Игра — статический сайт на HTML5 и JavaScript, без своего сервера в MVP. Движок — Phaser 4: бесплатный, открытый, работает в браузере на ПК и телефоне. Стабильная версия вышла в апреле 2026 года ([релизы Phaser 4](https://phaser.io/download/phaser4)).

| Требование | Значение |
| --- | --- |
| Движок | Phaser 4 (последняя стабильная 4.x) |
| Язык | JavaScript или TypeScript |
| Редактор уровней | Tiled (бесплатный), карты экспортируются в JSON |
| Браузеры | Chrome, Яндекс Браузер, Safari, Firefox — две последние версии; iOS Safari и Android Chrome |
| Устройства | ПК от 1280×720, телефоны от 360 px по короткой стороне, горизонтальная ориентация |
| Производительность | 60 кадров/с на ПК, не ниже 30 кадров/с на телефоне среднего уровня |
| Вес первой загрузки | До 10 МБ, остальные миры подгружаются по мере прохождения |
| Время загрузки | До 5 секунд на мобильном 4G до главного меню |
| Сохранение | Прогресс, ачивки и настройки — в localStorage браузера |
| Хостинг | Статический хостинг в РФ: Yandex Object Storage или поддомен сайта компании |
| Лендинг | Отдельная страница с кнопкой «Играть», описанием и картинкой для соцсетей |
| Аналитика | Яндекс Метрика с целями (ниже) |

| boss\_defeated | Побеждён босс |
| game\_complete | Пройден финал |
| credits\_link\_click | Клик по ссылке на сайт в титрах |
| share\_click | Клик «Поделиться» |

По этим событиям видно, на каком уровне игроки бросают игру и сколько людей дошли до титров.

### Персональные данные

В MVP игра не собирает имена, телефоны и почты, поэтому регистрация не нужна. Если позже появится лидерборд с почтой или названием компании:

- нужно согласие на обработку персональных данных отдельным документом, это требование действует с 1 сентября 2025 года ([разбор 1С](https://its.1c.ru/db/content/newscomm/src/495627.htm));
- данные хранятся на серверах в РФ;
- политику обработки данных и уведомление о cookie для Яндекс Метрики проверяет юрист.

## 9. Приёмка MVP

MVP готов к запуску, когда выполнены все пункты ниже.

- [ ] Пролог, Продажи, Цех, Склад и финал проходятся от начала до конца без багов, блокирующих прохождение.
- [ ] Полное прохождение занимает 15–25 минут у человека, который давно не играл.
- [ ] Не менее 4 из 5 тестировщиков-негеймеров прошли пролог с первых трёх попыток.
- [ ] Игра работает в браузерах и на устройствах из раздела 8, на телефоне — с экранными кнопками.
- [ ] Главное меню открывается за 5 секунд на мобильном 4G.
- [ ] Прогресс сохраняется после закрытия вкладки.
- [ ] Все события аналитики видны в Яндекс Метрике.
- [ ] Все тексты вычитаны: орфография, буква «ё», кириллица в шрифте отображается целиком.
- [ ] Тексты проверены по правилам безопасности юмора (раздел 6) и согласованы с руководством.
- [ ] В игре нет чужих брендов, логотипов и персонажей.
- [ ] На музыку, шрифты и графику есть лицензии или договоры.
- [ ] Формулировка про услуги в титрах согласована с коммерцией.

## 10. Пошаговый план реализации

Игру Евгения делает сама. Claude в чате — для геймдизайна и текстов, Claude Code — для кода, спрайтов, звука и публикации. Её роль — арт-директор и главный тестировщик: решать, что смешно и красиво, и проверять каждый шаг. Реальный срок MVP в одиночку параллельно с работой — 12–16 недель. В репозитории Phaser 4 есть папка skills со знаниями для ИИ-агентов, её стоит подключить к Claude Code ([анонс Phaser 4.0](https://github.com/phaserjs/phaser/discussions/7274)).

Если запуск нужен к Новому году (около 8 недель от 20 октября), MVP режем до пролога, Склада и финала, мини-игры — по минимуму.

### Инструменты и роли

| Задача | Инструмент | Что делает Евгения |
| --- | --- | --- |
| Геймдизайн, сценарий, диалоги, шутки | Claude в чате | Отбирает лучшее, правит тон, проверяет по правилам раздела 6 |
| Схемы уровней | Figma или Tiled | Рисует сама: ритм уровня лучше чувствует человек |
| Код игры | Claude Code + Phaser 4 | Ставит задачи по одной, проверяет в браузере и на телефоне |
| Спрайты и тайлы | Claude Code (спрайты кодом) + Figma или LibreSprite | Задаёт стиль, рисует ключевых персонажей, доводит пиксели вручную |
| Музыка и эффекты | Claude Code (синтез скриптом) + jsfxr | Слушает, выбирает, просит переделать |
| Публикация и аналитика | Claude Code + Яндекс Метрика | Заводит хостинг и счётчик, даёт доступы |
| Согласование | Руководство, коммерция | Показывает прототип и тексты |
| Тест | 5 коллег, 5–10 лояльных клиентов | Собирает отзывы |

### Графика и звук без художника

Claude не рисует картинки, как художник, но умеет «рисовать кодом». Для пиксель-арта с маленькими спрайтами и палитрой на 32–48 цветов это работает хорошо.

1. Каждый спрайт описывается сеткой символов, где символ — цвет из палитры.
2. Скрипт Claude Code превращает сетки в PNG-спрайтшиты для Phaser.
3. PNG открываются в Figma (сетка 1 px) или LibreSprite и доводятся вручную: лица, детали, кадры анимации.
4. Ключевых персонажей (стажёр, Шайба, Коррозия) Евгения рисует сама в Figma, массовку (болты, ящики, тайлы, мелкие враги) отдаёт генератору.

Пример сетки — болт-монетка 8×8:

```text
палитра: . прозрачный  K #16181c  S #9aa3ad  W #e6e9ec

..KKKK..
.KSSSSK.
KSWSSSSK
KSSSSSSK
KSSSSSSK
KSSSSSSK
.KSSSSK.
..KKKK..
```

Звук: музыку Claude Code синтезирует скриптом из списка нот и сохраняет в OGG, эффекты делаются в бесплатном браузерном генераторе jsfxr. Права на всё созданное своим кодом — у компании.

### Правила работы с Claude Code

- Одна задача за раз, с описанием результата и способа проверки: «враг ходит между двумя точками, при касании снимает одно деление здоровья».
- При ошибке — вставлять текст ошибки из консоли браузера целиком.
- Просить объяснить неочевидные решения перед тем, как принять их.
- Все принятые решения записывать в CLAUDE.md, чтобы новая сессия их знала.
- Не просить «сделай всю игру»: большие задачи агент выполняет хуже, чем серию маленьких.
