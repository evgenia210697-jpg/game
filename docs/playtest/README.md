# Тест прототипа на коллегах

По ТЗ (раздел 10, этап 3): дать поиграть 5 коллегам. «Если не весело — править механику, а не графику».

## Ссылки

- Игра: https://claude.ai/artifact/3fYcYgggwaFGjrrkU9cPos
- Анкета: https://claude.ai/artifact/C8tnA5BKDbFUjDWCyrtEno (исходник — `anketa.html` в этой папке)

Обе страницы приватные: перед тестом в каждой открыть «Поделиться» (Share) и дать доступ.

## Как собираются ответы

- Коллега с доступом «Участник» (Contributor) в пространстве claude.ai — ответ сохраняется на странице.
  Сводку и все ответы видит только автор анкеты; участник видит и правит только свой ответ.
- Все остальные (доступ «Просмотр», вход по ссылке без аккаунта) — после «Отправить» анкета показывает
  готовый текст с кнопкой «Скопировать»: его присылают в мессенджер или на почту.

## Вопросы

0. Как зовут (по желанию).
1. На чём играл(а): компьютер / телефон.
2. Дошёл(ла) до ворот отгрузки: с первого раза / не сразу / бросил(а).
3. Сколько раз уходил(а) «на перерыв»: ни разу / 1–2 / 3 и больше / кончались жизни.
4. Насколько было весело: 1–5.
5. Где было трудно или непонятно (текст).
6. Что понравилось (текст).
7. Захотелось сыграть ещё: да / может быть / нет.

Обязательные — 1, 2 и 4.

## Что смотреть в ответах

- Где бросают и где умирают — править сложность там, а не везде.
- «Трудно или непонятно» — каждый повтор одного места от двух человек — задача.
- Средняя оценка «весело» ниже 3 — править механику до графики (ТЗ).
