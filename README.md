# Заказ горит!

Браузерная пиксельная игра про закулисье оптовых поставок крепежа. ТЗ — [docs/TZ.md](docs/TZ.md).

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm run dev
```

Откроется адрес вида `http://localhost:5173`. Чтобы поиграть с телефона, подключи его к той же Wi-Fi сети
и открой адрес из строки `Network` в терминале.

Сборка для хостинга: `npm run build`, результат — в папке `dist/`.

## Управление

| Действие | ПК | Телефон |
| --- | --- | --- |
| Бег | Стрелки или A/D | ◀ ▶ слева |
| Прыжок | Пробел, W или ↑ | ▲ справа |
| Действие | E или Shift | E справа |
| Пауза | Esc | II в углу |
