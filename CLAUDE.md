# «Заказ горит!» — правила для Claude Code

Браузерная пиксельная игра-платформер для клиентов компании (крепёж, метизы).
Полное ТЗ: [docs/TZ.md](docs/TZ.md). Перед любой задачей сверяйся с ним.

## Как работаем

- Одна задача за раз. Делай ровно то, о чём попросили, — не трогай то, о чём не просили.
- Неочевидные решения сначала объясни, потом делай.
- Каждое принятое решение записывай в раздел «Решения» ниже, чтобы новая сессия его знала.
- Евгения проверяет каждую задачу в браузере и на телефоне. Пиши, как проверить результат.
- Общение и тексты в игре — на русском, с буквой «ё».
- Тексты в игре проверяй по «Правилам безопасности юмора» (ТЗ, раздел 6): никаких шуток про брак,
  сроки по вине компании, серые схемы; клиент никогда не злодей; никаких чужих брендов.

## Стек

- Phaser 4 (4.2.1) + Vite, чистый JavaScript (ES-модули).
- Знания по Phaser 4 для агента — в `.claude/skills/` (скопированы из npm-пакета `phaser/skills`).
  При обновлении Phaser скопируй их заново: `rm -rf .claude/skills && cp -r node_modules/phaser/skills .claude/skills`.
- Редактор уровней — Tiled, карты в JSON (пока не подключён).

## Команды

- `npm install` — поставить зависимости.
- `npm run dev` — дев-сервер; с флагом `--host`, чтобы открыть с телефона в той же Wi-Fi сети.
- `npm run build` — сборка в `dist/` (статика для хостинга).

## Структура

- `index.html` — страница, HTML-кнопки для телефона (`#touch`), заглушка «поверни телефон» (`#rotate`).
- `src/main.js` — конфиг Phaser, список сцен, масштабирование.
- `src/config.js` — константы: размеры, цвета, параметры движения героя.
- `src/input/touch.js` — экранные кнопки. `src/input/Controls.js` — единое управление (клавиатура + касания).
- `src/ui/` — элементы интерфейса (кнопка, полоска здоровья, счётчик болтов). `src/scenes/` — сцены: Boot, Menu, Level, Pause, Death.
- `src/objects/` — игровые объекты (враг, чекпоинт-проходная).

## Палитра

Основа из ТЗ: тёмный `#16181c`, акцент `#2d6bff` (каска героя, интерфейс), ржавые оранжевые — для злодеев.
Итоговая палитра 32–48 цветов ещё не утверждена. Все цвета — только через `COLORS` в `src/config.js`.

## Решения

- Разрешение 480×270, тайл 16, герой 16×32, `pixelArt: true`.
- Масштаб: `Scale.NONE` + свой расчёт зума в `main.js`. Если влезает ×2 и больше — целое число
  (ровные пиксели на ПК). Если нет (телефон 360 px по высоте) — дробный, иначе игра займёт полэкрана.
- Экранные кнопки — HTML поверх канваса, а не объекты Phaser: размер в настоящих пикселях
  (64 px, прыжок 76 px, пауза 48 px — по ТЗ не меньше 48), мультитач через Pointer Events.
  Показываются только на сенсорных устройствах и только в уровне.
- Кнопки интерфейса (меню, пауза, экран смерти) — 140×36 игровых px (`BUTTON` в `src/ui/button.js`),
  подпись 14px. На телефоне 360 px по высоте (масштаб ×1,33) это 187×48 px экрана — минимум по ТЗ.
  Новые кнопки не делаем меньше `BUTTON.height`; между кнопками — 8 игровых px.
- Прыжок прощает неточность: «койот» 100 мс и буфер нажатия 120 мс. Отпустил кнопку — прыжок ниже.
  Высота прыжка ≈ 60 px, поэтому подъём между опорами в уровнях — не больше 3 тайлов.
- Пауза: Esc, кнопка «II» на телефоне, автоматически при сворачивании вкладки.
  Уровень ставится на `scene.pause()`, поверх запускается сцена Pause.
- Здоровье — 3 деления, полоска в левом верхнем углу. Касание врага снимает одно деление,
  герой отлетает (250 мс без управления) и 1 с мигает и неуязвим — иначе за одно касание
  слетело бы всё здоровье. Настройки — `PLAYER` в `src/config.js`.
- Враги в сером прототипе — оранжевые квадраты 16×16, ходят между двумя точками (`ENEMY` в config,
  список `ENEMIES` в LevelScene). Убить врага пока нельзя, только перепрыгнуть.
  Ставим их только туда, где над головой свободно, иначе не перепрыгнуть.
- Болты в сером прототипе — серые кружки 8 px (цвета из сетки болта в ТЗ), список `BOLTS` в LevelScene:
  ряды по 2–6 штук на земле и платформах; ряды с подъёмом 40 px — над врагами, собираются прыжком.
  На тестовом уровне 71 болт. Счётчик — справа от полоски здоровья. Пока считается в пределах уровня
  и обнуляется при перезапуске; «+1 жизнь за 100 болтов» — вместе с задачей про жизни.
- Чекпоинт — турникет-проходная в середине уровня (`CHECKPOINT_X` в LevelScene). Пробежал — планка
  поднимается, всё синее, вверху экрана «Отметился на проходной!». Когда появится выбор пола героя —
  для героини «Отметилась».
- Здоровье кончилось — герой краснеет, через 0,7 с уровень встаёт на паузу и поверх открывается
  сцена Death: «Ушёл на перерыв. / Вернёшься?», кнопки «Вернуться» (Enter, пробел) и «В меню»,
  подсказка, откуда продолжишь. «Вернуться» — герой появляется на проходной (или в начале, если
  не отметился) с полным здоровьем и секундой неуязвимости. Уровень НЕ перезапускается:
  собранные болты остаются, враги ходят дальше. Для героини — «Ушла на перерыв».
  По ТЗ, когда кончатся жизни, уровень начинается заново целиком — это задача про жизни.
- Возврат с экрана смерти: `scene.resume(from, { respawn: true })`, а само появление — в первом
  кадре после паузы (`pendingRespawn`), когда часы сцены уже идут.
- На экране смерти повторы зажатой клавиши (`e.repeat`) игнорируем, иначе зажатый прыжок сразу его закроет.
- Флаги в сценах сбрасываем в `create()`, а не в конструкторе: сцена-объект переиспользуется при каждом запуске.
- Подписки на `this.events` сцены не снимаются при перезапуске сцены — отписываемся сами в `SHUTDOWN`.
- Шрифт временный (`monospace`). Нужен пиксельный с кириллицей и коммерческой лицензией.

## Открытые вопросы

- Пиксельный шрифт с кириллицей и лицензией — не выбран.
- На телефонах 19,5:9 по бокам остаются полосы. Возможно, позже расширять видимую область по ширине.
